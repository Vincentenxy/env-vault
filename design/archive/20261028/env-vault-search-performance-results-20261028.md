本轮本地验证已完成。小范围查询较快，标签和大范围查询需要先优化 SQL，再继续扩展搜索。

## A 核验结论
```callout warn 性能目标未全部达到
并发 5 的混合负载有 80 / 480 次查询超时。
功能断言通过，不代表延迟目标通过。
```
覆盖 1 万、10 万、100 万条环境实例，每档 19 个场景。
使用真实 JWT 验签、Redis 用户检查、AES 解密和搜索审计。

## B 百万规模的完整接口耗时
每场景 10 次采样，最近秩 P95 等于该组最大值。

| 场景 | P95 | 结果 |
| --- | ---: | --- |
| 稀有 Key | 8.1 ms | ok |
| 中文备注 | 30.0 ms | ok |
| 项目范围 | 116.5 ms | ok |
| 文件夹范围 | 52.7 ms | ok |
| 高频备注 | 3,329.9 ms | warn |
| 单标签 | 3,319.8 ms | warn |
| 多标签 + 高频 Key | 5,010.2 ms | no 10 次全部超时 |
| 标签候选首页 | 4,076.0 ms | warn 超出 500 ms 目标 |

## C 混合负载
每级预热 30 秒、测量 180 秒，完成在途请求后统计。

| 并发 | 请求 | 成功 | 超时 | P95 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 157 | 157 | 0 | 3,116.6 ms |
| 5 | 480 | 400 | 80 | 5,017.8 ms |
| 10 / 20 | — | — | — | 按方案停止升压 |

并发 5 时，稀有 Key 的 190 次请求全部成功，项目范围的 100 次请求全部成功。
主要失败来自高频备注、标签筛选和标签候选。

## D SQL 成本来自哪里
```flow LR
[候选环境行] -> [精确统计组数]: count
[精确统计组数] -> [分组与排序]: 重复处理大量命中
[分组与排序] -> [当前页详情]: 只返回 20 组
```
高频词 count 约 1,429 ms，分组分页约 1,673 ms。
分页排序落盘约 83.3 MiB。
单标签分页过滤掉 836,992 条无关连接结果。
标签候选只有 122 个，仍关联大量环境实例。
