Key、备注、标签检索已完成前后端接入。值检索和标签分类统计尚未开发。

## A 已实现的查询能力
| 能力 | 现有行为 |
| --- | --- |
| Key 和备注 | 任一字段命中，不区分大小写，包含匹配 |
| 中文搜索 | 支持中文备注，短关键词限制见下方规则 |
| 标签筛选 | 支持多个标签，命中任意一个即可 |
| 组合条件 | 范围、环境、关键词、标签取交集 |
| 多范围 | 租户、组织、项目、文件夹复选，范围之间取并集 |
| 环境筛选 | 同一项目及其目录可选环境，跨项目搜索全部环境 |
| 分页 | 按 groupId 分页，同一密钥的环境不会拆到不同页 |
| 标签候选 | 根据范围远程搜索和分页，只列存在有效绑定的标签 |

跨租户候选展示租户归属，同名标签仍按 ID 区分。当前只检索共享密钥，不包含个人密钥。

## B 已实现的页面能力
- 范围与环境筛选，以及范围与环境记忆
- 搜索框内的搜索说明、清空和提交操作
- 标签远程多选、候选分页和继续加载
- 范围、Key、标签合并单元格，一个环境一行
- 结果默认显示明文值，支持复制和手动隐藏
- 真实历史分页、版本详情和按需批次详情
- 切换条件取消旧请求，迟到响应不会覆盖新结果
- 局部加载、错误提示和重试

搜索结果不预加载历史，也不在本地保存关键词和明文结果。

## C 现有匹配和性能边界
全部范围、租户或组织搜索非空关键词时，需要至少三个连续的文字或数字。例如“密码”需先限定项目或文件夹，“数据库”可大范围搜索。

匹配方式是整个输入的包含匹配，不是分词或相似度搜索。用户输入的百分号和下划线作为普通字符处理。

同一项目必须指定有效环境。跨项目和租户、组织范围不能指定 envList。空关键词允许按范围或标签分页浏览。

后端使用 PostgreSQL pg_trgm GIN 索引方案，仅解密当前页，默认超时为五秒。没有全库解密扫描，也不缓存全量明文结果。
