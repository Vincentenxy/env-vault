标签绑定和标签搜索已完成。剩余工作分为未开发功能、权限中心依赖和部署验收。

## A 建议优先补齐
| 功能 | 当前已有 | 尚未开发 |
| --- | --- | --- |
| 用户锁定与解锁 | 锁定字段、认证拦截、Redis 查询 | 修改接口、管理操作、状态刷新 |
| 分片提交限流 | 登录限流、分片请求体限制 | 分片接口独立频率限制 |
| 全局审计日志中心 | 事件写入、指定资源的日志查询 | 跨资源分页查询、筛选、管理页面 |

用户锁定操作可先开发。审计中心的查询权限仍须等待权限中心。

## B 已预留基础的功能
| 功能 | 当前已有 | 尚未开发 |
| --- | --- | --- |
| 成员移除前移交负责人 | ResponsibilityChecker 扩展点 | 负责人检查、移交规则、阻止违规移除 |
| 项目分享流程 | 成员有效期模型、协作项目展示 | 邀请、接受、续期、撤销、到期通知 |
| 个人 Token 权限范围 | JWT 签发、加密保存、删除和锁定检查 | scope 模型、创建表单、路由及资源授权 |
| 审计查看入口 | 部分资源局部入口 | 个人密钥、用户、主密钥、登录认证入口 |

项目分享还缺分享审计和管理员查看能力。已删除资源也缺可访问的日志入口。

## C 按业务需要再设计
| 方向 | 边界 |
| --- | --- |
| 密钥值搜索 | 当前只搜索 Key、备注和标签，不搜索加密值 |
| 标签分类统计 | 当前已能筛选标签，尚无分类统计 |
| 单环境标签 | 当前按 groupId 跨环境共享，需求明确后再设计 |
| 新认证协议 | OIDC 直连、JWKS、opaque token、自定义 claim 映射 |
| 主密钥传输 mTLS | 当前使用共享内部令牌和 RSA 信封 |
| 独立 Gateway | 当前 API 代理和静态页面同属 Web 镜像 |
| 审计保留期清理 | 已记录到期时间，尚无分批清理任务 |

历史展示组件共用属于前端重构，不是缺少历史查询功能。

## D 权限中心接入后再做
- 租户、组织、项目、文件夹、密钥及环境访问控制
- 标签定义、绑定、候选查询和搜索结果权限过滤
- 历史版本和批次查询的环境权限过滤
- 项目分享范围、成员管理、日志查看和 PAT scope 授权

当前仅认证不等于已完成资源授权。按此前约定，这部分暂缓。

## E 待验证，不算未开发
- 公司统一退出地址和八小时会话下的 JWT 刷新策略
- 目标数据库的 pg_trgm、GIN 索引与生产规模压测
- CloudNativePG 多副本部署及故障切换，当前清单仍为单实例
- 外部入口的多节点高可用，不能仅凭 Controller 副本数判断
- Java SDK 对 tagList 的兼容性，当前工作区未提供该仓库

本次只核对本地代码与文档，没有检查运行集群和业务数据库。
